LM15 connects your application directly to model providers. Its SDKs share a common request and response model, without requiring an LM15 server between you and the provider.

## Start building

- **[Choose your language](/docs/languages/)** to find installation instructions and examples.
- **[Open the playground](/playground/)** to try JavaScript, Python, or Rust in your browser. Bring your own provider key; sending a message may cost money.
- **[Read the Python guides](https://lm15-dev.github.io/lm15-python/)** for the most extensive current tutorials and reference pages.

## One family, different levels of coverage

A shared design does not mean every language, provider, and model supports every feature. Check the documentation and tests for the implementation you plan to use.

The [shared contract](https://github.com/lm15-dev/lm15-contract) defines common behavior and includes test cases used to compare implementations.
