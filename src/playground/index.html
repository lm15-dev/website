    This provider blocks browsers

    The provider answered this page's request the way an API does when it refuses browser origins: the browser was not allowed to read the reply. Nothing was sent through lm15.

    lm15 runs a small relay for this case. If you allow it for this provider, your API key and your messages will pass through that relay on their way to the provider — a server we control, which keeps no log. Every other provider is still called directly from this page.

    The relay is not deployed yet; copy the code and run it outside a browser instead.
